RoboParty Roboto Origin — Prototype Wiring Guide

English translation of the RoboParty internal document. Original Chinese is kept in collapsible blocks under each section.
Source: 萝博头原型机（RoboParty Roboto Origin）走线说明 (Feishu wiki, space “【内部】RoboParty Roboto Origin资料”, author “萝博派对”, last modified 2 Sep 2026). Retrieved 12 Oct 2026.
Purpose of this page

This document describes how the Roboto Origin prototype is wired: which harness goes between which pair of joint motors, how the battery, charging port, main power switch, emergency stop, three‑in‑one power board and the RDK X5 computer are installed and connected, and how the harnesses and CAN ports are secured against vibration. The robot is symmetric, so the source only shows the right leg and the left arm; the other side is mirrored. The waist is a separate run with its own instructions.

2. Wiring

Context

The robot has a symmetric structure and the wiring rules are the same on both sides. The text below describes only the right leg and the left arm; wire the right arm and left leg the same way by mirroring. The waist is an independent cable run and must be wired as described in 2.2.

All motor numbers below are Slave IDs.

Wiring order (chain order along each limb):

  • Right arm: 0x13 – 0x14 – 0x15 – 0x16 – 0x17
  • Left arm: 0x0E – 0x0F – 0x10 – 0x11 – 0x12
  • Right leg: 0x07 – 0x08 – 0x09 – 0x0A – 0x0B – 0x0C
  • Left leg: 0x01 – 0x02 – 0x03 – 0x04 – 0x05 – 0x06
  • Waist motor: 0x0D – 0x07

2.4.1 Battery installation

Instructions
  • Battery protection: stick shock‑absorbing foam pads to the bottom and all four sides of the battery.
    • Purpose: damp the high‑frequency vibration during motion and prevent the battery sleeve from chafing through, which would risk a short circuit.
Warning (from the source)

This stage involves high‑current wiring. Always double‑check wire gauge and polarity.

Instructions
  1. Seat the battery: install the battery pack in its designated position on the base and make sure the centre of gravity is stable.
  2. Install the charging port:
    • Fix the charging socket to the robot’s back panel.

2.4.2 Main board installation

Instructions
  1. Solder the main power‑switch connector and the emergency‑stop switch (Fig. 17).
    ⚠️ Check the wire order — do not get it wrong! (Fig. 18, 19)
  2. Switch specification and photo of the real part: Fig. 20, 21. The switch’s lead colours map to: green → C (common), yellow → NO (normally open), white → NC (normally closed), black + red → lamp (lamp pins have no polarity). Variants: single‑colour 5‑pin, dual‑colour 6‑pin and 7‑pin.
  3. How the PCB backplate silkscreen maps to the real connection: Fig. 22, 23. Backplate pads for the main switch are 5V, GND, 5V_OUT, LED+; the E‑stop goes on 48VIN / 48V (Fig. 18).
  4. After testing that everything works, cut off the excess wire.
    Note: go by the position of the wires on the switch — the colour order of the wires may differ from batch to batch.
  5. Install the mounting parts. Carrier‑board print files: github.com/Roboparty/rpo_hardware … /A2_3D_print, files “PCB载板” (PCB carrier board) and “PCB转接板4.0” (PCB adapter board 4.0).
    • Fix with M3×16 screws from the underside (Fig. 24).
  6. Fix the three‑in‑one power board (Fig. 25, 26). Use standoffs to fix the three‑in‑one board and add standoffs to raise it (Fig. 27, 28).
  7. Fix the RDK X5. Use M3×8 to fix the RDK X5 to the main carrier board, then fix that assembly to the three‑in‑one board (Fig. 29, 30).

2.6 Board‑to‑board connections

Instructions
  1. The RDK X5 uses a USB‑A to Type‑C cable from one of its USB ports to the USB‑to‑CAN port on the three‑in‑one power board (Fig. 32, 33).
  2. The RDK X5 uses a Type‑C to Type‑C cable from the 5 V supply port on the three‑in‑one power board to the RDK X5 power input (Fig. 34, 35).
  3. The IMU and the gamepad receiver plug directly into the RDK X5 USB ports (Fig. 36).
  4. The voltage display connects via a GH1.25 connector.
  5. The port layout and pin definitions of the three‑in‑one power board are shown in Fig. 37, 38. Follow the silkscreen exactly and avoid reversed connections.

3. Fixing

3.1 Harness fixing

Instructions

Use harness clips (cable retainers) to fix each harness at its port, so that a loosening connector cannot cause unstable signal transmission (Fig. 39).

Original Chinese (3.1)
3.1 线束固定 线束固定方式：采用线束固定器将线束在端口处进行固定，防止因端口松动导致信号传输不稳定。

3.2 Port fixing

Instructions

To stop CAN connectors from coming loose or being torn off during motion, reinforce the ports with UV‑curing glue (Fig. 40).

Original Chinese (3.2)
3.2 端口固定 为防止 CAN 端口在运动过程中发生脱落或拽断，可使用 UV 胶对端口进行加固固定。

Translator’s notes and discrepancies

  • RBW_Origin_13 Body04 (CAN1, motor 0x0D → power board, XT30(+2)‑F.G.B — XT30U‑F, 50 cm) is used in 2.5 but missing from the BOM table in section 1.
  • For the leg/body harnesses the parenthetical GH1.25 lead length (30/30/50/35/30/65 cm) is 5–10 cm longer than the harness length column (25/25/40/30/20/60 cm). The translation keeps both numbers as written.
  • The waist motor 0x0D feeds the power board on CAN1 and chains into right‑leg motor 0x07, so CAN1 carries the waist + right leg, and CAN0 carries the left leg. This matches the bus assignment used in tools/README.md (can0 left leg, can1 right leg + waist).
  • “XT30(+2)‑F.G.B” is reproduced verbatim; it denotes the XT30 power connector with two additional signal pins (XT30(2+2)) used for CAN H/L. The meaning of the suffix “F.G.B” is not explained in the source.
  • The source does not state which USB port on the RDK X5 to use, nor the wire colours for the switch/E‑stop; it explicitly says colour order varies between batches, so go by position.
  • Image captions are derived from the surrounding text, not from the images themselves.
